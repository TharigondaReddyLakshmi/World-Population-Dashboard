# World-Population-Dashboard Using Powerbi
 World Population Analytics Dashboard  An interactive Power BI Dashboard designed to analyze global demographic distributions, gender ratios, and age structures across various geographic regions and countries.

# 📝 Dashboard Description

This business intelligence solution transforms global demographic data into actionable insights. It provides an intuitive interface to monitor male, female, and total population metrics simultaneously. By leveraging geographic mapping, trend analysis, and granular tabular reporting, the dashboard empowers researchers and policymakers to identify regional population density centers, age-group distributions, and gender balancing trends globally.

# 📊 Key Performance Indicators (KPIs) Used

The dashboard tracks core demographic metrics at a macro level using prominent high-level summary cards:

• Sum of PopMale (48.79M / 25.17%): Tracks the total male population across the filtered dataset.

• Sum of PopFemale (48.14M / 24.83%): Tracks the total female population across the filtered dataset.

• Sum of PopTotal (96.94M / 50%): Aggregates the combined global or regional population baseline.


# 📉 Charts and Visual Elements Used

• KPI Summary Cards: Placed at the top right to give an immediate, high-level snapshot of total male, female, and overall populations.

• Stacked Column Chart (Sum of PopMale, PopFemale & Total by AgeGrp): Displays population tiers broken down by specific age brackets (e.g., 5-9, 10-14, up to 55-59) to visualize generational demographics.

• Map Visualization (Sum of PopMale & PopFemale by Location): A Microsoft Bing map layer that plots population metrics across global continents and major countries (India, China, United States, etc.).

• Donut Chart (Sum of PopMale & PopFemale & PopTotal): Illustrates the macro percentage split between male and female distributions globally.

• Data Matrix / Table: A detailed tabular view at the bottom right that matches exact population counts against specific country locations, complete with column totals.

• Single-Select Slicer (Location): A scrolling filter panel on the right allowing users to isolate data by specific countries alphabetically (from Afghanistan onwards).

# 🎯 Conclusion & Key Takeaways

• Balanced Gender Ratio: The global dataset exhibits a highly balanced gender split, with males accounting for 25.17% (48.79M) and females accounting for 24.83% (48.14M) of the total mapped population.

• Youth Bulge Demographics: Population density heavily skews toward younger demographics, peaking in the 5-9 and 10-14 age cohorts (averaging ~14.6M each) before experiencing a steady, linear decline in older age groups.

• Geographic Concentration: Core population weight is heavily concentrated within the Asian subcontinent (led significantly by India and China), visible via the centralized plot clustering on the map visualization.
